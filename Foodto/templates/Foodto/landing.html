¿Qué es Foodto?

Una plataforma web inteligente diseñada para mejorar la seguridad alimentaria mediante el uso de modelos de Inteligencia Artificial.




Inteligencia Artificial aplicada a la alimentación

Foodto permite analizar una fotografía de un plato para reconocer el alimento mediante un modelo de Deep Learning basado en ResNet18.


Una vez identificado, un modelo de lenguaje genera automáticamente un informe detallado indicando los posibles alérgenos presentes, proporcionando una ayuda rápida para personas con alergias o intolerancias alimentarias.


Todo el proceso se realiza desde una interfaz sencilla y accesible para cualquier usuario.

Objetivos del proyecto


✔ Reconocer alimentos mediante visión artificial.


✔ Detectar automáticamente posibles alérgenos.


✔ Facilitar una herramienta de apoyo para mejorar la seguridad alimentaria.


✔ Integrar modelos modernos de Inteligencia Artificial dentro de una aplicación web.


✔ Sentar las bases para futuras funcionalidades orientadas a personas con discapacidad visual.

¿Cómo funciona Foodto?

El proceso completo dura solo unos segundos y está diseñado para ser sencillo, rápido e intuitivo.

📷

1. Captura una imagen

El usuario toma una fotografía del plato o selecciona una imagen desde su dispositivo.

🧠

2. La IA reconoce el alimento

Un modelo ResNet18 entrenado con PyTorch identifica el tipo de comida mediante visión artificial.

⚠️

3. Obtén el análisis

Un modelo de lenguaje genera automáticamente un informe con los posibles alérgenos detectados.

Tecnologías utilizadas

Foodto integra diferentes tecnologías modernas para ofrecer una solución basada en Inteligencia Artificial.

Django

Framework utilizado para desarrollar toda la aplicación web, gestionar usuarios y administrar el historial.

PyTorch

Biblioteca de Deep Learning utilizada para entrenar y ejecutar el modelo de clasificación.

ResNet18

Red neuronal convolucional entrenada para reconocer alimentos a partir de imágenes.

Groq

Plataforma utilizada para realizar inferencias rápidas sobre modelos de lenguaje.

GPT-OSS

Modelo de lenguaje ejecutado sobre Groq, encargado de generar una explicación clara de los posibles alérgenos encontrados.

SQLite

Base de datos utilizada para almacenar usuarios e historial de análisis realizados.

Arquitectura del sistema

Cada componente de Foodto participa en una cadena de procesamiento inteligente para obtener un análisis completo.

Captura de la imagen

El usuario envía una fotografía del plato desde la interfaz web.

Clasificación mediante IA

El modelo ResNet18 identifica automáticamente el alimento presente en la imagen.

Análisis de alérgenos

El nombre del alimento es enviado a un modelo de lenguaje vía Groq, que genera un informe sobre los posibles alérgenos.

Resultado final

El usuario recibe un informe claro, comprensible y queda almacenado en su historial personal.

Preguntas frecuentes

Algunas dudas habituales sobre el funcionamiento de Foodto.

¿Foodto sustituye la información del fabricante?

No. Foodto es una herramienta de apoyo basada en Inteligencia Artificial que ayuda a identificar posibles alérgenos, pero siempre debe complementarse con la información oficial del fabricante o del establecimiento.

¿Qué precisión tiene el reconocimiento?

El sistema utiliza un modelo ResNet18 entrenado para clasificación de alimentos. La precisión depende de la calidad de la fotografía y del alimento mostrado.

¿Se almacenan mis análisis?

Sí. Cada usuario dispone de un historial privado donde puede consultar todos los análisis realizados desde su cuenta.

¿Qué tecnologías utiliza?

Django, PyTorch, ResNet18, SQLite y Groq para combinar visión artificial con modelos de lenguaje.
